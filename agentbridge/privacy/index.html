Privacy Policy

Last updated: March 30, 2026

The short version: AgentBridge does not collect, store, or transmit any data. All communication stays on your local network.

Overview

AgentBridge is a local communication tool between AI agents and Classic Mac OS computers. It operates entirely on your local network through shared folders. No data is sent to external servers.

Data Collection

We do not collect any data.

Neither the Classic Mac application nor the MCP server collects, transmits, or stores any information on external servers. Specifically:

  • No personal information is collected
  • No usage analytics or tracking
  • No telemetry of any kind
  • No internet connection required or used
  • No cloud services

How Communication Works

AgentBridge communicates through text files in a shared folder on your local network. Commands are written as text files to an inbox folder; responses are written to an outbox folder. This communication:

  • Never leaves your local network
  • Uses only the shared folder you configure
  • Contains only the commands and responses you initiate through the AI agent
  • Is ephemeral — command and response files are consumed after processing

MCP Server

The MCP server runs locally on your modern computer. It translates MCP protocol calls into text files for the shared folder. It does not make any outbound network connections.

Open Source

The MCP server source code is available on GitHub under the GPL v3 license. You can inspect exactly what it does.
